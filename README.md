# Crate

**Your Spotify Liked Songs, sorted by what they sound like.** Crate tags every song you like with its genre, style, BPM, musical key, energy and vibe, then turns any combination of those into a Spotify playlist with one tap. Every morning it also builds **Crate Daily**: 30 songs you don't have yet, picked from your taste and from genres you rarely play.

A personal system for one Spotify account. iPhone and Android apps, no server, no subscription, no AI at runtime. Open source (MIT).

## What it does

- **Tags your whole library automatically.** Every night, each new Liked Song gets a genre family and style (from its sound, cross-checked with Last.fm, Discogs and Beatport), tempo with half/double-time detection, Camelot key, energy 1–10 and vocal/instrumental. The apps show how many sources agree ("3 of 4 sources agree"), and you can correct anything.
- **Builds playlists from filters.** Pick genres and styles, vibes ("Hypnotic", "Dark", "Sunday"…), community tags ("italian", "dub techno"), a BPM range, energy, a key with compatible keys, vocals, and a size. The count updates live. **Send** replaces your Spotify playlist **Now** with a shuffled selection.
- **Vibes, defined by example.** A vibe is a few tracks or artists you choose; Crate finds the songs that sound like them, within a similar energy. Untick a song to keep it out.
- **Presets everywhere.** Save a filter as a preset ("Dark 138+", "Warehouse") and send it from a home-screen widget, Siri or the Action Button (iPhone), or a launcher shortcut (Android).
- **From Spotify's share sheet.** Share a song to Crate to see its tags, send **More like this → Now**, or like it so it gets tagged tonight.
- **Crate Daily.** A fresh 30-track discovery playlist every morning: 20 from your taste (rotating genres, so it isn't dominated by what you have most of) and 10 from genres you have little of. Likes teach it what to pick next.
- **Looks after itself.** A daily health check, problem-only phone alerts (ntfy), and automatic dependency updates.

Crate only ever writes two playlists, **Now** and **Crate Daily**; everything else in your Spotify account is read-only to it.

## How it works

```
Spotify Liked Songs ──► GitHub Actions (nightly, free) ──► data/*.json in a private data repo ◄──► iPhone & Android apps
   Deezer previews → Essentia audio models · Last.fm · Discogs · Beatport (by hand)            Send → Spotify "Now"
                     daily: Crate Daily playlist · health check · alerts
```

There's no server: a private GitHub repo is the database, GitHub Actions is the computer, and the apps talk straight to Spotify and GitHub. This public repo holds only the code; personal data never lives here.

## Repository

```
pipeline/   Python package `crate`: sync, analyse, tags, consensus, vibes, query, daily, health (uv run crate --help)
ios/        iPhone app: CrateKit Swift package, app, widget and share extension (Xcode project generated by ios/tools)
android/    Android app: core (Kotlin port of CrateKit) and app (Compose, Glance widgets, share target)
spec/       shared test vectors: Python, Swift and Kotlin must all pass them
ops/        the private data repo's scheduled workflows and setup notes (data/ itself is private)
docs/       handoff guides, runbook, architecture, query rules
.github/    tests and android-release workflows; composite actions shared with the data repo
```

## Run your own

Crate is built for one person's library, so running it means your own copy:

1. Fork this repo and create a **private** data repo from [`ops/data-repo`](ops/data-repo/README.md) (workflows, secrets, the `CRATE_CODE_REPO` variable).
2. Create a Spotify app at [developer.spotify.com](https://developer.spotify.com/dashboard) (Development mode allows a handful of users) and put its client ID in `CrateIdentity.spotifyClientID` (iOS and Android).
3. Point the apps at your data repo (`AppConfig`), then follow [the runbook](docs/runbook.md#first-time-setup-m0).
